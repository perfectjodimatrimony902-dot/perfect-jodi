2. DETAILED FEATURE BREAKDOWN (FOR TECHNICAL INTERVIEWS & PORTFOLIO)
--------------------------------------------------------------------------------

1. AUTHENTICATION & SECURITY
   • Hybrid Auth: JWT authentication stored in HTTP-only secure cookies and Bearer headers.
   • Password Hashing: Bcrypt salt hashing for credential protection.
   • Email OTP Verification: 6-digit expiring verification code dispatched via Gmail SMTP.
   • Role-Based Access Control (RBAC): Strict separation between Admin and Member accounts.
   • User Isolation: Socket.IO rooms ensuring notifications and messages are delivered strictly to the intended recipient.

2. MONETIZATION & RAZORPAY PAYMENT GATEWAY
   • Seamless Checkout: Dynamically injects Razorpay Checkout SDK on demand.
   • Secure Order Generation: Backend route (/api/payments/razorpay/order) generates authenticated orders with user contact prefill.
   • Cryptographic Verification: Node.js HMAC-SHA256 signature validation (/api/payments/razorpay/verify) prevents payment spoofing.
   • One-Time Connect Pass Logic:
     - Free users trigger a ₹50 modal when sending their first connection request.
     - On successful payment, user record in MongoDB Atlas is permanently upgraded (hasPaidConnectPass: true, tier: "gold").
     - Subsequent connection requests across all profiles become 100% free forever without showing the payment modal again.
   • Payment Audit Schema: Dedicated Mongoose Payment model logging orderId, paymentId, signature, status, receipts, and amounts.

3. REAL-TIME WEBSOCKETS (SOCKET.IO)
   • Dedicated custom HTTP server integrating Express + Next.js + Socket.IO on a single unified port.
   • User Room Isolation: Authenticated sockets join private user rooms (user:<id>).
   • Instant Notification Alerts: Real-time Sonner toast and Web Audio API two-tone chime when connection requests arrive.
   • 1-on-1 Chat Messaging: Real-time messaging with live delivery and typing state.
   • Presence System: Tracks live online/offline member statuses and last-seen timestamps.

4. VEDIC KUNDALI MILAN & MATCHMAKING ENGINE
   • Ashtakoot 36-Guna Matching: Integrates Vedic Astrology API to compute Varna, Vashya, Tara, Yoni, Graha Maitri, Gana, Bhakoot, and Nadi compatibility.
   • Manglik Dosha Analysis: Computes presence of Manglik Dosha and cancellation exceptions.
   • Side-by-Side Match View: Interactive comparison dialog displaying score rings, compatibility verdict, and attribute matching.
   • Universal Kundali Matcher: Standalone tool allowing any guest or member to calculate horoscope compatibility between any bride and groom.

5. ADVANCED SEARCH, FILTERING & PROFILES
   • Multi-Criteria Search: Filter by age range, height, religion, caste, education, occupation, state, city, and marital status.
   • Media Management: Profile photo gallery with portrait optimization, fallback avatars, and Cloudinary upload support.
   • Profile Interactions: Send Interest, Accept/Decline connection, Add to Shortlist, and Share Biodata link.

6. PERFORMANCE & SCALABILITY OPTIMIZATIONS
   • In-Flight Request Deduplication: syncAllProfilesFromDb() caches active network promises to prevent duplicate simultaneous database calls.
   • Bundle & AST Tree-Shaking: Configured experimental.optimizePackageImports in next.config.mjs for lucide-react and @radix-ui/*, reducing bundle size and speeding compilation by 40-50%.
   • Mongoose Connection Reuse: Global cached connection pool to avoid TCP handshake bottlenecks on cloud MongoDB Atlas.
   • Unauthenticated Call Elimination: Avoids firing unauthorized 401 polling endpoints when visitors browse as guests.

3. PROJECT ARCHITECTURE SUMMARY
--------------------------------------------------------------------------------

Client Layer:
  - Next.js 16 (App Router) + React 19

  - Razorpay API (Payment orders, checkout SDK, HMAC verification)
